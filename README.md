# E-Commerce Sales Data Analysis Using Python

## Project Overview

This project analyzes e-commerce sales data using Python to identify sales trends, category performance, regional performance, profitability, and top-selling products.

## Objective

The objective of this project is to analyze sales data and generate useful business insights that can support data-driven decision-making.

## Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code
- Git & GitHub

## Dataset

The dataset contains e-commerce order information including:

- Order details
- Customer information
- Product information
- Category
- Region
- Sales
- Quantity
- Discount
- Profit
- Order and shipping dates

## Data Analysis

The project includes:

- Data loading and inspection
- Missing-value analysis
- Duplicate-value checking
- Data cleaning
- KPI calculation
- Sales by category
- Profit by category
- Sales by region
- Profit by region
- Monthly sales trend
- Top 10 products by sales

## Key Findings

- Technology generated the highest sales and profit among the categories.
- Furniture generated relatively high sales but significantly lower profit compared with Technology and Office Supplies.
- The West region recorded the highest sales and profit.
- The Canon imageCLASS 2200 Advanced Copier was the highest-selling product by sales.
